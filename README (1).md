# 📋 스튜디오 일지 자동 작성기

스튜디오 장비 예약 내역을 붙여넣으면, 기존 종이 일지 양식 위에 자동으로 정보를 채워 인쇄할 수 있는 웹 도구입니다.

---

## 🚀 바로 사용하기

👉 **[https://[사용자명].github.io/[레포명]/studio_log_v2.html]()**

> 별도 설치 없이 브라우저에서 바로 실행됩니다.

---

## ✨ 주요 기능

- 예약 사이트에서 복사한 텍스트를 그대로 붙여넣으면 자동 파싱
- 기존 일지 이미지 위에 좌표 기반으로 텍스트 오버레이
- 날짜, 대여자, 대여 시간, 장비 수량, 층수 체크박스 자동 입력
- 일지 양식에 없는 장비는 기타 장비 칸에 자동 표시
- 공동작업자 메모 자동 분리
- 브라우저 인쇄(Ctrl+P) → PDF 저장 지원
- 단일 HTML 파일 — 오프라인 완전 작동

---

## 📖 사용 방법

### 1단계 — 예약 내역 페이지 열기
예약 사이트에서 본인의 예약 상세 페이지를 엽니다.

### 2단계 — 전체 선택 후 복사
아래처럼 **예약내역 ~ 목록 버튼 위**까지 드래그해서 선택한 뒤 `Ctrl+C`로 복사합니다.

```
예약내역
시설선택   스튜디오 C7-312
장비       갓(3), 조명/ Fomax E600(2), ...
예약일시   2026-04-27
사용일시   2026-04-29 / 17:00 ~ 21:00
예약자 정보
이름       홍길동
메모       수조(1) 공동작업자 김철수
```

### 3단계 — 붙여넣기 후 생성
입력창에 `Ctrl+V`로 붙여넣고 **✨ 일지 생성** 버튼을 누릅니다.

### 4단계 — 인쇄
**🖨️ 인쇄** 버튼 또는 `Ctrl+P`로 출력하거나 PDF로 저장합니다.

---

## 📥 지원 입력 형식

별표(`*`) 없는 새 양식과 별표 있는 구 양식 모두 지원합니다.

| 항목 | 인식 방식 |
|------|-----------|
| 장비 | `장비명(수량)` 형태, `조명/` `필수/` `렌즈/` 접두어 자동 제거 |
| 날짜 | `예약일시` 줄의 `YYYY-MM-DD` |
| 대여 시간 | `사용일시` 근처 `HH:MM` |
| 대여자 | `이름` 줄 다음 값 (빈 줄 있어도 자동 skip) |
| 층수 | 시설 코드 `C7-3xx` → 3층, `C7-4xx` → 4층 자동 체크 |
| 공동작업자 | 메모 내 `공동작업자 이름` — 앞뒤 어디 있어도 자동 분리 |
| 기타 장비 | 양식에 없는 장비는 기타 칸에 자동 표시 |

## 🛠️ 유지보수 가이드

### 새 장비 추가 시

`studio_log_v2.html` 내부의 두 곳을 수정합니다.

**① `COORDS` 객체에 좌표 추가**
```javascript
'장비명': { qty: { x: 63.4, y: 20.0 }, check: { x: 31.9, y: 20.3 } },
```

**② `DEFS` 배열에 매핑 추가**
```javascript
{ keys: ['입력할 장비명', '약칭'], target: '장비명', type: 'qty-check' },
```

| type | 동작 |
|------|------|
| `qty-check` | 수량 + 체크박스 |
| `num` | 수량만 |
| `text` | 텍스트 표시 |

### 일지 양식 이미지 교체 시

```python
import base64
with open('새일지.jpg', 'rb') as f:
    print('data:image/jpeg;base64,' + base64.b64encode(f.read()).decode())
```

출력값으로 HTML 내 `<img src="data:image/jpeg;base64,...">` 부분을 교체한 뒤, 모든 좌표를 다시 측정합니다.

### 예약 사이트 입력 형식이 바뀔 경우

`parseInput()` / `parseEquip()` 함수의 정규식을 수정합니다.
